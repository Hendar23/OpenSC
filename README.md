# OpenSC
OpenSC is an open-source game remake for playing Criterion Games' [Sub Culture](https://en.wikipedia.org/wiki/Sub_Culture). Built with [Godot](https://godotengine.org/)

[Watch some gameplay footage here.](https://www.youtube.com/watch?v=AqHBXfEzc-o)

The aim is to bring this forgotten little gem of a game to modern systems, preserve the original experience, and expand on it with improved gameplay, new features and modding support. 

## Current Progress
OpenSC is now a fully playable beta. All the core systems are in place. The remaining missions and equipment are being added and playtested.

## Installation
Latest release is available [here](https://github.com/Hendar23/OpenSC/releases/tag/v0.8.0)
- OpenSC does not include the original Sub Culture game assets. You'll need your own copy of the original game files.
- When you first run the game, it will ask you to point it to the original Sub Culture folder.
- A controller is recommended for controlling the sub.

## Enhancements
OpenSC offers a few enhancements over the original:

### Gameplay & Physics
- **Player Sub**
  - Reworked and enhanced player sub physics.
- **Missiles**
  - Renamed missiles to torpedoes.
  - Longer powered range.
  - Fuel-exhaustion: instead of removal at flight expiry, they stop producing bubbles, stop homing, coast, tumble and sink, exploding on contact with the seabed or another obstruction.

### Missions & NPCs
- **Mission Improvements**
  - Lots and lots of little enhancements. Things like mission related subs and items not just vanishing into thin air. More dramatic explosions for buildings and big subs.
- **NPCs**
  - NPCs use docks.
  - Random Pirates (and bounties for killing them).
  - Reworked NPC movement.

### Interface & Quality of Life
- **New main menu**
  - Replaced static main menu with a live in game view.
- **Photo and Action Replay Modes **
  - Pauses the game and gives full camera control for taking screenshots.
  - Replay the last 30 seconds of action from any angle.
- **UI**
  - Compact multi-message radio stack
  - Credits and hold inventory displayed next to full screen map

### Mod Support
Mod support for visual and gameplay enhancements. A handful are available at the moment:

- Replacement 3D sea-mine model. Open source model, credits below.
- Clownfish reskin/addition. Made by me in MSPaint in about five minutes to test adding more wildlife.
- 3D HUD instruments with live displays. AI generated (yuck, I know) but just to demonstrate modding possibilities. If any Blender wizard out there wants to remake them, please do!
