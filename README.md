# OpenSC
OpenSC is an open-source game engine remake for playing Criterion Games [Sub Culture](https://en.wikipedia.org/wiki/Sub_Culture)

Built with [Godot](https://godotengine.org/)

Latest release is available [here](https://github.com/Hendar23/OpenSC/tags)
- You will need a copy of the original Sub Culture files. It has been abandonware for years now. Google is your friend.
- A controller is recommended.

For development, install Godot and either add `godot` to your PATH, set `GODOT_PATH` to its executable, or put the executable's full path (without quotes) in `.local/godot-path.txt` before using the launch scripts. The `.local` folder is excluded from Git. Saves and preferences are stored in `Documents/OpenSC`, including when running from source. The tracked configuration files provide shared game defaults; personal settings do not overwrite them. Keep any additional private workspace exclusions in `.git/info/exclude`.
