# OpenSC
OpenSC is an open-source game engine remake for playing Criterion Games [Sub Culture](https://en.wikipedia.org/wiki/Sub_Culture)

You will need a copy of the original Sub Culture files. It has been abandonware for years now. Google is your friend.

Built with [Godot](https://godotengine.org/)

There is no release yet, but if you want to play about with the current version:
- Install Godot
- Download the OpenSC files
- Run Launch Game.
- Use a controller.

Implemented so far
- Submarine movement, animated pods/propellers, bubbles, positional sounds, and controller rumble.
- First/third-person cameras, headlights, HUD panels, exploration minimap, and full-screen map.
- Docking/undocking, correct city names, approach greetings, animated radio portraits, and improved departure camera.
- Docked interface with save/load slots.
- Live main menu with an occasional passing submarine.
- Rebindable player controls.
- Working zapper.
- Wildlife AI, schooling, fleeing.
- Fish explosions!
- Day/night cycle.
- Plants deform and sway
- Editor tools for the map and entities.
- Floating mines with explosions.
- Mod support.
- Sub damage and shield repair
- Thorium crystals
- The suck-o-matic
